# TigerFlow Pipeline

[TigerFlow](https://github.com/princeton-ddss/tigerflow) is a lightweight pipeline framework for running tasks on directories of files, with support for both local execution and Slurm HPC clusters. The `src/remarx/tigerflow/` directory contains a TigerFlow pipeline for running sentence embedding at scale on a Slurm cluster like Della.

TigerFlow operates on directories: it takes a directory of input files, runs a task on each file in parallel, and writes results to a parallel output directory.

### Pipeline

```
corpora/*.csv  →  [embed_sentences]  →  embeddings/embed_sentences/*.npy
```

Input is a directory of sentence corpus CSVs as generated by `remarx-create-corpus`, each with a `text` column containing one sentence per row. Output is a directory of `.npy` binary files, each containing a float32 numpy array of shape `[num_sentences, 768]`, L2-normalized, with row order matching the input CSV.

The default model is `paraphrase-multilingual-mpnet-base-v2`, configurable via `params.model_name` in `config.yml`.

### Running on Della

#### Setup

Install the `slurm` optional dependency:

```bash
uv pip install "remarx[slurm]"
```

Edit `config.yml`: ensure `kind: slurm`, set `--account` in `sbatch_options` to the faculty sponsor's Slurm account (not your personal account), and update `setup_commands` to activate your conda environment.

#### Set up the HuggingFace cache

Compute nodes have no internet access, so the model must be cached before submitting jobs. The cache should live in your personal scratch directory. Set the `HF_HOME` environment variable so HuggingFace knows where to find it:

```bash
export HF_HOME=/scratch/gpfs/CDHRSE/<netid>/huggingface-cache
```

To populate the cache, copy the model files from your local environment to the scratch cache directory. **Do not load the model on the head node** — loading HuggingFace models requires significant RAM and should not be done on shared login nodes.

Then set `hf_home` in `config.yml` under `params:` to the same cache path. TigerFlow will configure HuggingFace to load from the cache without making network requests.

#### Running

From the `src/remarx/tigerflow/` directory, run the pipeline by passing the input corpus directory and the output embeddings directory:

```bash
cd src/remarx/tigerflow/

tigerflow run config.yml \
  /path/to/corpora/ \
  /path/to/embeddings/
```

TigerFlow will submit one Slurm job per worker (up to `max_workers`), each processing a subset of the input files. You can monitor per-file status and overall completion counts with:

```bash
tigerflow report /path/to/embeddings/
```

This prints a table showing which files are pending, in progress, completed, or failed.

### Local testing

To run locally without Slurm, make two changes:

In `embed_sentences.py`, change the import and class definition to use `LocalTask` instead of `SlurmTask`:

```python
from tigerflow.tasks import LocalTask

class EmbedSentences(LocalTask):
```

In `config.yml`, set `kind: local` and remove `max_workers`, `worker_resources`, and `setup_commands`.

### Using the output

Each `{name}.npy` file corresponds to the `{name}.csv` input and is written to `embeddings/embed_sentences/`. Row order is preserved, so embeddings can be used directly with `find_quote_pairs()`.
