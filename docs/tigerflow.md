# TigerFlow Pipeline

The `src/remarx/tigerflow/` directory contains a [TigerFlow](https://github.com/princeton-ddss/tigerflow) pipeline for running sentence embedding at scale on a Slurm HPC cluster like Della.

### Pipeline

```
corpora/*.csv  →  [embed_sentences]  →  embeddings/embed_sentences/*.npy
```

Input is a sentence corpus CSV as generated by `remarx-create-corpus`, with a `text` column containing one sentence per row. Output is a float32 numpy array of shape `[num_sentences, 768]`, L2-normalized, with row order matching the input CSV.

The default model is `paraphrase-multilingual-mpnet-base-v2`, configurable via `params.model_name` in `config.yaml`.

### Running on della

#### Setup

Install the `slurm` optional dependency:

```bash
pip install "remarx[slurm]"
```

Edit `config.yaml`: set `--account` in `sbatch_options` to your Slurm account, and update `setup_commands` to activate your conda environment.

If worker nodes lack internet access (as on Della), pre-download the model to a shared cache directory before running:

```bash
python -c "from sentence_transformers import SentenceTransformer; SentenceTransformer('paraphrase-multilingual-mpnet-base-v2')"
```

Then set `hf_home` in `params` to the cache directory (defaults to `~/.cache/huggingface`). TigerFlow will configure HuggingFace to load from the cache without making network requests.

#### Running

```bash
cd src/remarx/tigerflow/

tigerflow run config.yaml \
  /path/to/corpora/ \
  /path/to/embeddings/
```

Monitor progress:

```bash
tigerflow report /path/to/embeddings/
```

### Local testing

To run locally without Slurm, change `kind` to `local` in `config.yaml` and remove `max_workers`, `worker_resources`, and `setup_commands`.

### Using the output

Each `{name}.npy` file corresponds to the `{name}.csv` input and is written to `embeddings/embed_sentences/`. Row order is preserved, so embeddings can be used directly with `find_quote_pairs()`.
